# Jongsoo Lee — Academic homepage

A lightweight, responsive academic portfolio for GitHub Pages.

## Publish

1. On GitHub, create a **public** repository named **jongsoolee.github.io**.
2. Upload `index.html` to the root of the repository (Add file → Upload files → Commit changes).
3. Open Settings → Pages and choose **Deploy from a branch**, branch **main**, folder **/(root)**. Save.
4. Visit `https://jongsoolee.github.io` after deployment finishes.

## Edit

Everything is in `index.html`. Use GitHub's pencil Edit button to edit text and Commit changes.
- Portrait: replace `https://github.com/jongsoolee.png` with a local `profile.jpg` (and upload that image).
- Email, CV, and Scholar: add your verified links in the Profile and Contact sections.
- More papers: duplicate a `.paper` block in Publications.
- Experience/Education dates are intentionally minimal until verified.

No npm, bundler, paid plan, or external dependencies required. The GitHub avatar is loaded from GitHub, so you may want to replace it with a portrait.
